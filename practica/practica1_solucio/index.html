    Pràctica 1 — Projecte inicial Symfony (Windows + XAMPP)

    1. Creació de la carpeta de treball

    La carpeta equivalent en Windows amb XAMPP és:

    1
    C:\xampp\htdocs\symfony

    Si no existeix, la creem.

    2. Creació del projecte Symfony (estructura "mínima")

composer require symfony/maker-bundle --dev

    Carpeta resultant:

    1

    3. Configuració del domini local i Virtual Host

    3.1 Modificar el fitxer hosts

    Obrir com a administrador:

    1
    C:\Windows\System32\drivers\etc\hosts

    Afegir al final:

    1
    127.0.0.1   symfony.tendaNomAlumne

    Guardar.

    3.2 Configurar Virtual Host en XAMPP

    Obrir:

    1
    C:\xampp\apache\conf\extra\httpd-vhosts.conf

    Afegir:

    ServerName symfony.tendaNomAlumne
    DocumentRoot "C:/xampp/htdocs/symfony/tendaNomAlumne/public"

    <Directory "C:/xampp/htdocs/symfony/tendaNomAlumne/public">
        AllowOverride All
        Require all granted
        Options FollowSymLinks

    CustomLog "logs/tenda_nom_alumne_access.log" common
</VirtualHost>

    Comprovar que en C:\xampp\apache\conf\httpd.conf està descomentat:

    1
    Include conf/extra/httpd-vhosts.conf

    3.3 Reiniciar Apache

    Des del XAMPP Control Panel:

    1
    Stop → Start (Apache)

    3.4 Comprovació

    Obrir navegador:

    1
    http://symfony.tendaNomAlumne

    Ha de mostrar la pàgina d'inici de Symfony.

    4.1. Instal·lació de dependències després de clonar el projecte

    Quan pugem un projecte PHP a GitHub, la carpeta vendor no es puja perquè està exclosa mitjançant .gitignore. Aquesta carpeta conté totes les dependències gestionades per Composer, i per tant, no s’ha de versionar.

    ⚠️ Atenció: la carpeta vendor no està inclosa en el repositori.

    Per això, si descarreguem el projecte en un altre ordinador o entorn de treball, la carpeta vendor no existirà.

    En eixe cas, és necessari reinstal·lar totes les dependències executant la següent instrucció dins de la carpeta del projecte:

    1
2
3
4
5
    # 1) Reinstal·lar dependències
composer install

# 2) Regenerar caché (no necessari)
php bin/console cache:clear

    Aquesta ordre:

    • Llegix el fitxer composer.json.
    • Descarrega totes les llibreries necessàries.
    • Reconstrueix la carpeta vendor.
